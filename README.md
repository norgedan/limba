# Limba sfâșiată · Det sønderrevne språket

**Live:** https://norgedan.github.io/limba/

O conversație despre limba română, ce i s-a făcut și ce a supraviețuit — în română și norvegiană.

En samtale om det rumenske språket, hva som ble gjort med det og hva som overlevde — på rumensk og norsk.
